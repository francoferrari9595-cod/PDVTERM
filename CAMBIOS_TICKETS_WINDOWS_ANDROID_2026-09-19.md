# Tickets de Windows visibles/cobrables desde Android

- Nuevo acceso rápido: Ver y cobrar tickets de Windows.
- Muestra tickets abiertos creados directamente en Windows.
- Solo permite agregar productos y cobrar cuando Windows tiene `allow_android_charge=1`.
- Si la opción está deshabilitada, Android funciona en modo solo lectura.
- El ajuste solo puede ser modificado por ADMINISTRADOR en Configuración de Windows.
- El cobro usa la misma lógica de caja/medios de pago y, al finalizar, limpia el ticket de Windows.
